# Shifer

Шифратор-дешифратор на Flutter: зеркальный шифр, Цезарь и Цезарь с ключевым словом.

## Запуск

Flutter должен быть в PATH (локально: `C:\Users\user\flutter\bin`).

```bash
flutter pub get
flutter run -d windows
flutter run -d chrome
flutter run
```

## Возможности

- Карусель шифров на главном экране
- Мгновенное шифрование / дешифрование в обе стороны
- Алфавиты: русский, английский, немецкий + свои шаблоны
- Язык интерфейса: русский / English
